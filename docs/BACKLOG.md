A `unix` layer shared with Linux comes **after** a macOS build compiles, and only for what it proved equal — 8 of the 26 capabilities are the same syscall, and `libc::ucred`/`SO_PEERCRED` are not among them. **How it gets launched**, the three shapes weighed on 2026-11-19: (a) a `.app` bundle is a directory, not a toolchain — `Contents/{Info.plist, MacOS/tortty, Resources/tortty.icns}`, `CFBundleExecutable` naming the binary, `codesign -s - --force` on the bundle (every arm64 Mach-O needs **some** signature or the kernel kills it, `Killed: 9`, even from a shell, and `/usr/bin/codesign` ships with the OS), and `open -a Tortty --args --debug-socket …` carries arguments — this is what `install.sh` writes in place of the `.desktop` it writes on Linux, and today `install.sh` has no Darwin branch at all; the only part that needs a Mac is the `.icns` (`sips` + `iconutil`), which can also be generated once and committed; (b) a `.command` file is two lines (`exec ~/.local/bin/tortty "$@"`) and is double-clickable, but only by opening Terminal.app first — a terminal to open a terminal, so it stays the debugging shape, not the product one; (c) Shortcuts.app with *Run Shell Script* needs no bundle, gives no `/Applications` entry and no icon of its own, runs the process inside Shortcuts' context, and whether the window takes focus there is unmeasured. **Gatekeeper is not what blocks any of them**: quarantine (`com.apple.quarantine`) is written by the *downloading app* (Safari, Finder, not the network) and read by LaunchServices when a bundle or `.dmg` is opened, so the `curl … \| bash` path never sets it, and `install.sh:153` already downloads with `curl -fsSL` — notarization therefore buys the Finder double-click, not the install. What launching from Finder does change is the environment: minimal `PATH`, no `LANG`, no `TERM` from the user's shell, so the child `zsh` cannot see Homebrew — the honest fix is spawning a **login** shell (`$SHELL -l`) rather than wrapping the binary in a `sh` that loads the environment, because a wrapper puts a shell in the process tree and complicates `hangup`/`child_cwd`. None of this is measured: without a Mac it is derived from the mechanism (quarantine, LaunchServices, the arm64 signature rule), and the first three probes are `codesign -dvv` on a cross-built binary, running it unsigned to see the kill, and `curl \| bash` on a real Mac |
